# JDBC 批量新增入仓任务

## 业务目标
通过批量上传工具快速创建多个 JDBC 抽数任务，并经过标准审批流程，实现数据从业务库向数仓的合规入仓。

---

## 业务流程

```
[步骤1] 准备配置数据
    ↓
[步骤2] 批量上传校验
    ↓
[步骤3] 确认校验明细
    ↓
[步骤4] 提交审批工单
    ↓
[步骤5] 业务审批
    ↓
[步骤6] 任务发布生效
```

---

## 业务步骤

### 步骤1：准备配置数据
**做什么**：业务人员根据需求，在 Excel 模板中填写待入仓的库表信息及调度策略。
**关键信息**：数据源实例、库名、表名、负责人、抽数方式（增量/全量）、调度周期。
**输出**：批量配置 Excel 文件。

### 步骤2：批量上传校验
**做什么**：用户在系统中上传 Excel 文件，系统自动检查库表是否存在、权限是否合规、配置项是否完整。
**输入**：配置 Excel 文件。
**输出**：批量操作任务记录（TaskId）。
**执行组件**：[TKI_003] 批量上传校验接口。

### 步骤3：确认校验明细
**做什么**：用户查看上传后的校验反馈，确认所有待新增的任务均解析成功，无错误行。
**业务规则**：[TKR_001] 校验所有行必须 100% 通过方可进入下一步。
**执行组件**：[TKI_004] 查询校验结果。

### 步骤4：提交审批工单
**做什么**：用户正式提交任务，系统生成 BPM 审批工单，任务进入待审批状态。
**输出**：BPM 工单号、审批流程 ID。
**执行组件**：[TKI_005] 提交批量操作任务。

### 步骤5：业务审批
**做什么**：管理人员或合规负责人在审批中心对该批量任务进行审核。
**业务动作**：
- **审批通过**：触发底层配置发布。
- **审批拒绝**：流程中断，任务回滚。

### 步骤6：任务发布生效
**做什么**：审批通过后，系统自动生成底层入仓配置，任务在调度引擎中生效。
**预期结果**：数据源配置、抽数节点、调度策略等业务对象在系统中完整创建。
**业务规则**：[TKR_007] 入仓任务发布成功判断。

## 业务场景

### 场景1：批量新增任务全链路成功
**业务描述**：业务人员填写正确的文件并获得审批通过，任务成功发布。
**前置条件**：业务人员拥有上传及申请权限。
**关键步骤**：填写文件 -> 上传校验成功 -> 提交工单 -> 审批人点击通过。
**预期结果**：系统生成正式的入仓任务，可在调度列表中查看。

### 场景2：审批拒绝场景
**业务描述**：由于配置不合规，审批人在审核阶段拒绝了该申请。
**业务步骤**：提交工单 -> 审批人点击拒绝。
**预期结果**：批量操作状态变更为“失败”，工单记录中可见拒绝原因，系统不生成正式入仓任务。

```

    ↓ (审批通过)
[TKD_008] 数据源配置 + [TKD_007] 抽数节点 -> [TKD_006] 任务发布
```
